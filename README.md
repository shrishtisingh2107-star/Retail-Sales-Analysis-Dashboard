# Retail-Sales-Analysis-Dashboard
## Project Overview
This project is created using Microsoft Excel to analyze retail sales data and generate meaningful business insights.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Dashboard Design
- Data Visualization

## Dashboard Features
- Total Sales Analysis
- Total Profit Analysis
- Total Orders
- Category-wise Sales Analysis
- Monthly Sales Trend
- Customer and Product Insights

## Data Cleaning Steps
- Removed duplicates
- Handled missing values
- Corrected data formatting
- Created calculated columns

## Key Insights
- Identified top-performing categories
- Analyzed sales and profit trends
- Compared business performance metrics
